# Archive

Older reference implementations from 2025, kept for history. They predate the current
portfolio and are not maintained.

- `gpu-ml-pipeline/` — superseded by [`rtb-gpu-inference`](../rtb-gpu-inference).
  Its benchmark tables are illustrative and were not produced by code in the folder.
- `recommendation-system/` — superseded by [`rtb-edge-scale-out`](../rtb-edge-scale-out).
- `multi-agent-orchestration/` — a generic multi-agent RAG system, superseded by
  [`gpu-analytics-nl2sql`](../gpu-analytics-nl2sql). Its metrics table was not produced by
  code in the folder.
- `conversational-ai/` — a generic voice-pipeline reference (speech recognition, intent,
  speech synthesis), superseded by [`healthcare-dialog-agents`](../healthcare-dialog-agents).
- `retail-vision-analytics/` — a generic DeepStream/Jetson retail-vision platform, superseded
  by [`edge-vision-retail`](../edge-vision-retail). Its impact and benchmark tables were not
  produced by code in the folder.
- `fraud-detection/` — an older real-time fraud-detection reference (Spark Streaming,
  Kafka), retired as dated.

GitHub only runs workflows from the repository root, so the CI files inside these folders
do not run.
